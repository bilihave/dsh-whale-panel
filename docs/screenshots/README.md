# 截图 / 录屏（欢迎 PR）

这个目录是**占位**：我不方便录屏，所以先把它开在这里，等社区来补。
有图的可视化比十段文字更有说服力，尤其对这个插件的「浮窗感」。

## 想要哪几张

按重要性排，任选其一都算贡献：

| 文件（建议命名） | 内容 | 为什么想要 |
| --- | --- | --- |
| `learn.png` | 学习页：兴趣画像的词大小/透明度随权重变化，鼠标悬停在某个词上 | 一眼看出「画像真是学出来的」 |
| `run.png` | 运行页：日上限 ¥ → token 的实时换算、峰谷时段提示 | 成本模型最容易被误解，一张图讲完 |
| `budget-on.png` | 运行页：金额 → token 换算 + 峰谷时段提示（同一个「确认制」输入框） | 说明「花的是额度不是次数」 |
| `monitor.gif` | 监测台：事件流滚动 + 试播受限提示 | 展示「可观测」这个卖点 |
| `power-off.png` | 标题栏总开关拨到「已关闭」后的样子 | 证明插件可以彻底停手 |
| `watched.png` | 记录页第一块「它看过的 N 条」，带 `plugin` 标记 | 说明观看历史这条边界 |

GIF 建议 3–5 秒、≤ 3 MB（GitHub 直接嵌 `![...](docs/screenshots/xxx.gif)` 就行）；PNG 建议宽度 ≤ 1200。

## 提交前请务必遮住这些

截图里很容易带出隐私，**提交前请打码或裁掉**：

- [ ] 主人号 / 发言号的 **UID、昵称、头像**
- [ ] 二维码区域（`login.start` 之后那一块）
- [ ] 预算金额、token 用量——如果不想公开你自己的用量
- [ ] 浏览器标签页、任务栏、系统通知
- [ ] 评论区里别人的昵称/头像

推荐做法：只截**浮窗本体**（可以先把浮窗拖到纯色背景上），或者用系统的矩形截图工具别带桌面。

## 怎么提

1. 放进本目录，文件名用上表建议的名字（多张就加后缀 `learn-2.png`）；
2. 在 README 的「截图」一节把对应的 `<!-- 待补充 -->` 换成 `![说明](docs/screenshots/xxx.png)`；
3. 开 PR，标题写 `docs: 截图 — <页面名>`。

谢谢，真的会用到。
